 Описание

Веб-приложение «Калькулятор» в фирменной стилистике маркетплейса Wildberries.


- Арифметические операции: `+`, `−`, `×`, `÷`
- Ввод десятичных дробей, смена знака, процент
- Сброс (`C`)
- Переключение тёмной/светлой темы
- Выбор акцентного цвета (фиолетовый / розовый / синий)


- HTML5
- CSS3 (Grid, CSS-переменные, анимации)
- JavaScript (Vanilla)


- `calculator.html` — разметка
- `style.css` — стили
- `script.js` — логика


Откройте `calculator.html` в браузере.
